# Bibaling translation standards

These are the current authoritative translation instructions for the Bibaling book translator:

- `bibaling_gpt_instructions_v8_parent_led.txt` — parent-led translation workflow and decision rules.
- `bibaling_slovenian_verse_guide_v4.txt` — Slovenian rhyme, meter, naturalness, and read-aloud quality rules.

Later-numbered files supersede earlier prompt and verse-guide iterations. Application prompts should use both documents as source material; older versions are retained only outside this repository for history.

These files are product references. Adding them to the repository does not automatically load them into an API request—the generation pipeline must explicitly incorporate them.
