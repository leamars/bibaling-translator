# Llama Llama — published Spanish reference

Evaluation-only reference bundle supplied by Lea from a published Spanish edition.

## Contents

- `pages/`: the 14 supplied page-pair images, retained in reading order.
- `transcript.md`: a manual, line-preserving transcription of the visible Spanish text.
- `quality-observations.md`: lessons for Bibaling's Spanish evaluation and translation-quality work.

## Use and limits

This material is a style and evaluation reference, not a hard-coded translation, production UI asset, or reusable training corpus. The supplied pages do not show enough bibliographic information to identify the edition, translator, or regional market with confidence. Until that metadata is added, the language should not be treated as a Spain-Spanish gold standard.

The published translation is also not automatically correct for every Bibaling product priority. It demonstrates strong read-aloud craft, but occasionally compresses source or picture detail. Bibaling should assess naturalness, poetic craft, and fidelity separately.
